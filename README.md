# Abhinav Jha — Premium Personal Brand Portfolio

A personal branding website crafted for **Abhinav Jha**, MBA candidate in **Finance & Marketing** at **IILM University, Greater Noida**.

Engineered for the **Digital & Social Media Marketing** curriculum, this platform combines:
1. **Premium Glassmorphism** (Midnight Navy `#10182D`, Electric Violet `#6657D9`, Soft Blue `#829BFF`, frosted glass with 24px backdrop blur).
2. **Luxury Editorial Minimalism** (Warm Ivory `#F4EFE6`, Soft Peach `#E9A88E`, Charcoal `#24252D`, *Playfair Display* & *Manrope* typography).
3. **Interactive Motion Graphics & Hand-Drawn Annotations** (Animated gradient mesh orbs, hand-drawn SVG chart & funnel sketches, animated signature, and 3D card tilt).
